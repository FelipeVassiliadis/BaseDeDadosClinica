# BaseDeDadosClinica

Projeto de base de dados em PostgreSQL para a gestão de uma clínica de fisioterapia (pacientes, funcionários, atendimentos, consultas, tratamentos e sessões).

Este trabalho foi realizado **em dupla**, no âmbito da disciplina de **Base de Dados**, no ano letivo de **2024** (2024/25).

## Estrutura

| Ficheiro | Descrição |
|---|---|
| `ddl.sql` | Criação da base de dados, tipos enumerados e tabelas |
| `dml_insert.sql` | Inserção de dados de exemplo |
| `views.sql` | Views (`atendimento_administrativo`, `atendimento_medico`) |
| `proc_func.sql` | Funções e triggers de validação |
| `queries.sql` | Consultas ao modelo |
| `Grupo 10.pdf` | Relatório do trabalho |

## Como executar

Executar os scripts pela ordem: `ddl.sql` → `dml_insert.sql` → `proc_func.sql` → `views.sql` → `queries.sql`.
